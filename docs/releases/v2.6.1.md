# Openbentt 2.6.1

OpenCode connection + chrome fix.

## Fixes

- `opencode run` / `models` use `--standalone` so a busy managed service port no longer yields empty chat replies or a stuck **auto** model picker
- Provider/auth errors (e.g. budget exceeded) surface clearly
- Default model prefers `opencode/*` free ids
- Sidebars sit below the frameless title bar — Edit / View / Help stay visible

## Verify

```bash
opencode models --standalone | head
opencode run --standalone --format json --model opencode/big-pickle "hi"
```
