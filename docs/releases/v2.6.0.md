# Openbentt 2.6.0

Calmer chrome, leaner composer, workspace recent folders.

## Highlights

- Center status pill for runtime / approvals (opens right Controls card)
- Composer `+` menu: attach + Tools only
- Set workspace: high-contrast Browse + recent folder history
- Empty chat: larger “Ready when you are.” (logo removed from welcome)
- Gentleface icons on chrome / sidebar (line idle, solid active)
- Tools dialog trimmed to real modes + calculator

## Install (Linux local)

```bash
npm run build && npx electron-builder --linux dir --publish never
bash scripts/install-local-linux.sh
openbentt
```
