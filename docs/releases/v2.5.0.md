**Date:** 22 Nov 2026

## Highlights

- **Prism / Overleaf / Codex import** — ZIP and folder one-click into Notebook projects (plus existing `.tex` / `.bib` / Zotero).
- **Multi-agent providers** — desktop PATH auto-detect for OpenCode, Claude Code, Codex CLI, Cursor Agent, Aider, Gemini CLI; prefer any detected agent in Settings → Agents.
- **Updates & settings** — Desktop update card on Settings; check / download / restart & install via `electron-updater`.
- **Bombadil browser QA** — `npm run test:bombadil` property-based exploration against the preview URL.
- **Landing news** — `/news` release notes so visitors see v2.5.0 updates from the home page News strip.

## Migrating from OpenAI Prism (shutdown ~1 Jan)

OpenAI’s Prism LaTeX editor is shutting down. Openbentt is a local-first replacement path:

| Prism need | Openbentt |
|------------|-----------|
| Edit LaTeX | Notebook studio (CodeMirror) |
| Compile PDF | BusyTeX → local TeX → HTTP → text PDF cascade |
| Project ZIP | Import .zip / folder (Overleaf-compatible layout) |
| References | `.bib` + Zotero integration |
| AI assist | Local Ollama / OpenRouter / detected agent CLIs |

Export your Prism project as a ZIP (or copy the folder), then **Projects → New → Import**.
