# Openbentt 2.6.2

Chat wait UX, Paper log persistence, job strip polish.

## Fixes

- Empty OpenCode replies no longer hide the assistant bubble — **Thinking** and agent activity show immediately while Stop is active
- OpenCode failures surface the **real error** and force-expand agent logs
- PaperOrchestra **live engine logs** (and stage / output dir) survive navigating Notebook → Chat → Paper via a main-process ring buffer
- TaskCenter paper chip keeps updating while Notebook is unmounted (`PaperProgressBridge`)

## Polish

- Global job strip briefly shows **done** chips; TaskCenter toasts auto-dismiss
- **Answer ready** in-app toast when a reply finishes in the background
- Packaged `sql.js` trimmed to the WASM runtime only (~30 MB smaller pack)

```bash
npm run test:electron
npm run build
npx electron-builder --linux dir
bash scripts/install-local-linux.sh
```
